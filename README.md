# web-portfolio

This is the site for my university task. 

This project is a responsive personal portfolio website built using HTML5 and CSS3. The website presents information about me, my skills, and my projects in a clean and structured layout.
The main goal of this project was to practice using HTML structure, CSS styling, and layout creation using Flexbox. The design focuses on simplicity, readability, and responsive behavior across different screen sizes.

**Features**

Responsive layout using Flexbox
Sections: About Me, Skills, Projects, Contact
Clean and minimalist design
Hover effects and basic UI styling

**Technologies Used**

HTML5
CSS3
Flexbox

**Responsive Design**

The layout adapts to different screen sizes using flexible containers and alignment properties
